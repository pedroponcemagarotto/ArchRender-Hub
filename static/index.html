CONTROLE DO SEU ACERVO

Backup e dados.

Sua biblioteca é privada e fica armazenada neste computador. Mantenha cópias de segurança.

Exportar biblioteca

Baixe um arquivo de backup com receitas, campos, imagens anexadas e favoritos. Guarde-o em outro disco.

Restaurar backup

Importe um backup criado pelo ArchRender Hub. Receitas com os mesmos identificadores serão substituídas.

Dados protegidos por padrão

O servidor responde somente no endereço 127.0.0.1. Seus arquivos permanecem na pasta data ou na pasta indicada por ARCHRENDER_DATA_DIR. Nenhuma imagem é enviada automaticamente à nuvem.

Aviso da versão inicial

O backup JSON comporta até 90 MB de imagens e a restauração é limitada a 120 MB por arquivo. Para uma biblioteca maior, copie a pasta data com o servidor desligado; a restauração de grandes coleções será ampliada numa próxima versão.
